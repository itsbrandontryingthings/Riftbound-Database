# Riftbound Database

A free card database and collection tracker for the Riftbound trading card game: every printing with pictures, TCGplayer prices in CAD and USD, pack quick-add, a deck checker and the competitive ban list.

Everything a visitor enters (card counts, decks) is saved only in their own browser.

Card data from [Riftcodex](https://riftcodex.com); prices from TCGplayer.
